# 🎓 Upcoming Student Conferences

A list of **upcoming conferences students can attend, present at, or get scholarships for** — student & diversity conferences, academic CS venues with paper deadlines, and industry/developer conferences. **Updated automatically every day.**

🔎 **Prefer search & filters? Use the website →** https://gkarpe2204.github.io/student-conferences/

🙏 **Know a conference that's missing? [Submit an issue](../../issues/new/choose)** or add it to [`data/watchlist.yml`](data/watchlist.yml) in a PR.

**Legend:** 🆕 added in the last 7 days · ⏰ deadline within 14 days · 🌐 online/hybrid · ⚠️ dates scraped automatically — confirm on the site

### How this list is built

A GitHub Action runs [`tracker/`](tracker/) once a day. It pulls:

| Source | What it adds |
|---|---|
| [`data/watchlist.yml`](data/watchlist.yml) | Curated student conferences (dates entered by hand, or scraped from each site) |
| [ccfddl/ccf-deadlines](https://github.com/ccfddl/ccf-deadlines) | Academic CS conferences + paper deadlines, CORE/CCF rank |
| [tech-conferences/conference-data](https://github.com/tech-conferences/conference-data) | Industry & developer conferences + CFP deadlines |
| Web search (optional) | New student conferences found via Serper (Google results) or Brave Search |

Past conferences drop off automatically. Data is also published as JSON at [`data/conferences.json`](data/conferences.json).
